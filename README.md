# EN-SEÑA / EN-SEÑA

## Español

EN-SEÑA es un proyecto web educativo enfocado en la enseñanza del lenguaje de señas.  
Su objetivo es promover la inclusión y facilitar la comunicación entre personas sordas y oyentes mediante contenido accesible.

### ¿Qué incluye el sitio?
- Página principal con introducción al proyecto.
- Sección de servicios/cursos.
- Información de profesores.
- Planes o precios.
- Eventos.
- Página de contacto.

### Tecnologías usadas
- HTML5
- CSS3
- JavaScript
- Bootstrap y librerías visuales incluidas en `assets/vendor`

### Estructura principal
- `index.html`: inicio del sitio.
- `cursos.html`, `profesores.html`, `precios.html`, `eventos.html`, `contacto.html`: páginas internas.
- `assets/`: estilos, scripts, imágenes y librerías de terceros.

---

## English

EN-SEÑA is an educational web project focused on teaching sign language.  
Its goal is to promote inclusion and improve communication between deaf and hearing people through accessible content.

### What does the website include?
- Home page with a project introduction.
- Services/courses section.
- Teachers information.
- Pricing plans.
- Events section.
- Contact page.

### Technologies used
- HTML5
- CSS3
- JavaScript
- Bootstrap and visual libraries included in `assets/vendor`

### Main structure
- `index.html`: website home page.
- `cursos.html`, `profesores.html`, `precios.html`, `eventos.html`, `contacto.html`: internal pages.
- `assets/`: styles, scripts, images, and third-party libraries.
